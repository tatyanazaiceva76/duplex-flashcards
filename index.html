Duplex flashcards with a measured back offset

Turn one explicit two-column CSV or TSV list into paired front/back printable HTML. Start with the unshifted calibration pair; a correction moves only the BACK content.

Three-step workflow

  1. Calibrate: download the two-page pair and print it at 100% / actual size, without browser headers or footers.
  2. Measure in BACK view: look at the BACK with its TOP marker upright. Ring right of cross = positive X; ring below cross = positive Y.
  3. Generate: enter that measured displacement. The file applies the opposite translation to BACK content only.

Card data and print settings

Zero while unchecked means unmeasured / no correction, not a passed calibration. Accepted offsets are −5 to +5 mm.

What this does — and does not do

The tool keeps card IDs paired, mirrors BACK positions for the selected flip edge, preserves incomplete-sheet blank slots, and applies one constant translation. It does not correct skew, scale, rotation, changing feed, variable displacement across corners, printer margins, driver behavior or font differences. Test plain paper before a batch.

Generic CSV-to-duplex tools already exist, including Flashy and Formatter’s flashcard maker. Existing-PDF page shifting is available from tools such as PnP Buddy. This tool composes text-table layout and a measured back-view translation; it does not claim uniqueness or a physical printer repair.

Privacy: entered card text is processed in this page. The app does not upload or persist it and uses no analytics, accounts, cookies or storage. Loading these same-origin page files and choosing an external reference link still uses the network.

Before printing a full deck

Measure from the BACK, with TOP upright

Hold the unshifted test sheet against light and look at its BACK. Compare the back ring with the front cross. If the ring is 3 mm right and 2 mm up, enter X = 3 and Y = −2. The back content is then moved 3 mm left and 2 mm down in that back-page view. A measurement taken while looking at the front has a different sign convention: do not enter it here.

Check several corners and another sheet. A single translation cannot repair different offsets across the page, rotation, scale changes or inconsistent paper feed. Keep the paper, driver, feed path, duplex edge and scale unchanged when testing your correction. The tool does not measure or configure your printer.

What will I download?

A standalone, script-free HTML document: each physical sheet has a FRONT page followed by its BACK page. Open the file in a browser and check the page count and chosen paper in Print or Save as PDF. Use actual size / 100%, turn browser headers and footers off, and match the selected flip edge. This tool does not directly create or verify a PDF. Test plain paper before printing a batch or cutting cards.

Which table formats are supported?

Choose comma CSV or tab TSV explicitly. With the header option checked, the first row must be front,back (or front and back separated by a tab). Both cells in every data row need text. Quoted fields may contain commas, quotes or line breaks. Up to 64 cards and 240 Unicode code points per field are accepted, but text that needs more than six lines is refused rather than clipped. No Anki package, PDF, images or vendor-specific export is read.
